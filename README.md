# Sneakers 👟

A responsive, modern sneaker e-commerce storefront website built with HTML, CSS, and JavaScript.

🔗 **Live Demo:** [https://gokul05102003.github.io/Sneakers/](https://gokul05102003.github.io/Sneakers/)

---

## ✨ Features

- Clean and modern storefront UI
- Interactive sneaker showcase and product browsing
- Responsive layout for desktop and mobile devices
- Lightweight, fast-loading vanilla frontend

## 🛠️ Built With

- **HTML5** – Page structure and semantic markup
- **CSS3** – Styling and responsive layout
- **JavaScript** – Interactive functionality
